# 7. 应用类型

| 类型 | 适用场景 | 包格式 | 提交格式 |
|---|---|---|---|
| Deb 应用 | 直接运行在宿主机的二进制程序/脚本 | 标准 `.deb` 包 | Deb 包（单包模式）或 tar.gz 压缩包（双包模式）+ 配置文件 |
| Docker 应用 | 需要独立运行环境的服务 | Docker 镜像 + docker-compose.yml | Compose 文件 + 配置文件 |

根据应用特性选择合适类型：

- **选择 Deb** — 如果你的应用是原生二进制、Python 脚本（利用系统预装 Python 3.10）或轻量级系统服务。**注意：Node.js、Java、Go 等语言运行时非系统预装，Deb 应用不可直接依赖。**
- **选择 Docker** — 如果你的应用需要特定运行环境、依赖复杂或已有容器化版本

> **混合类型应用：** 当原生启动器管理 Docker 容器时，应用包可同时包含 Deb 和 Docker 组件。此时使用 `"application_type": "deb"` 并在 `depend` 中声明 `["DockerEngine"]`。Deb 组件作为 Docker 服务的启动器/管理器。

**application_type 取值说明：**
- `"deb"` — 单包模式（标准 Deb 包）
- `"deb-TarGz"` — 双包/压缩包模式
- `"docker"` — Docker 应用
